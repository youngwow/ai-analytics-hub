# Архив внутри репозитория

Здесь ничего не удалено. Файлы вынесены из активной навигации, потому что они относятся к прошлому состоянию проекта или фиксируют решения до выбора архитектуры MVP.

- `pre-mvp-docs/` — ранние технические, ML, monitoring и risk-черновики. В них есть полезные идеи, но также есть преждевременные решения и неподтверждённые пороги.
- `checkpoint_04_09/` — промежуточные материалы сдачи от 04.09.2026; они не должны использоваться как финальная презентация или описание.
- `macos_metadata/` — перемещённые служебные `.DS_Store`.
- `legacy-pointers/` — старые файлы-указатели, ссылки из которых переведены сразу на канонические документы.

Возврат любого решения из архива требует повторной сверки с [`project/00_ГЛАВНЫЙ_ПУТЬ_AI_PRODUCT_HACK.md`](../project/00_ГЛАВНЫЙ_ПУТЬ_AI_PRODUCT_HACK.md).
