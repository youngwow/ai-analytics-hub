# Результаты прогонов

Эксперту достаточно шести точек входа:

1. [`FINAL_VERIFICATION.md`](./FINAL_VERIFICATION.md) — последняя техническая проверка репозитория.
2. [`EVIDENCE_PACK.md`](./EVIDENCE_PACK.md) — единая карта гипотез, решений и границ доказанного.
3. [`b2/B2_V4_DECISION.md`](./b2/B2_V4_DECISION.md) — выбор AI-конфигурации и честная граница review-first.
4. [`b3/B3_EVIDENCE.md`](./b3/B3_EVIDENCE.md) — итог полного E2E, масштаба и доресерча.
5. [`b4/B4_MANUAL_AUDIT.md`](./b4/B4_MANUAL_AUDIT.md) — авторитетный содержательный аудит.
6. [`b3/HUMAN_PILOT_PROTOCOL_V1.md`](./b3/HUMAN_PILOT_PROTOCOL_V1.md) и [`b3/PILOT_EXCEL_BASELINE_V1.xlsx`](./b3/PILOT_EXCEL_BASELINE_V1.xlsx) — готовый пользовательский gate: Excel против MVP.

В активных папках оставлены только выбранные конфигурации, финальные повторы и прогоны, на которые опираются решения. Черновые, невалидные и заменённые прогоны сохранены в [`_archive/benchmark-history`](../_archive/benchmark-history/).

Для финального чтения авторитетны только документы выше. Старые benchmark-runs сохраняются как воспроизводимая история, но не заменяют итоговые решения.
