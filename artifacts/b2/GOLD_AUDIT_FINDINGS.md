## Решение

`v2` не используется для дальнейшей настройки или доказательства абсолютного качества. `v3` строится полево:

1. Для каждого поля принимается значение, поддержанное минимум двумя из трёх источников.
2. Поле без большинства помечается `unresolved` и исключается только из метрики этого поля; материал остаётся в остальных задачах.
3. Existing must-facts/evidence не переписываются этим голосованием и проходят отдельную смысловую проверку.
4. Раскрытые splits v2 больше не являются закрытым holdout. Они используются для development/validation диагностики.
5. Новый holdout создаётся и замораживается только после фиксации prompt; его gold не используется для настройки.

## Ограничение

Это улучшенная внутренняя разметка, но всё ещё не customer gold. LLM-аудиторы сами входят в сравниваемый класс моделей, поэтому результаты используются для обнаружения разногласий и majority, а не выдаются за независимую пользовательскую истину.
