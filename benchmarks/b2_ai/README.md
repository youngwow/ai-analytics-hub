# B2 AI benchmark

Замороженная диагностическая корзина для сравнения AI-конфигураций. Она покрывает известные продуктовые и технические риски, но не выдаётся за статистическую модель промышленного потока GS Labs.

## Что уже готово

- `data/v1` (`v1.0.0`) — замороженная финальная корзина первого цикла: 68 материалов, 8 событийных кейсов, 6 траекторий НПА и 10 изолированных RAT-материалов;
- `prepare_input.py` — создаёт пакет без ground truth;
- `prediction.schema.json` — архитектурно нейтральный контракт ответа;
- `run_benchmark.py` — запускает любую внешнюю реализацию;
- `evaluate.py` — считает точные метрики и формирует отдельный пакет смысловой проверки.
- `judge_response.schema.json` и `validate_judge.py` — фиксируют контракт смысловой оценки и не позволяют принять неполный ответ judge.
- `make_oracle_prediction.py` — только self-test scorer на скрытом эталоне; его результат запрещено выдавать за результат продукта.

Целостность замороженной версии:

```bash
python benchmarks/b2_ai/validate_dataset.py
```

Промпты, модель и архитектура продукта намеренно не входят в benchmark. Результатов нет до появления первой реализации агента.

## Подготовка входа

```bash
python benchmarks/b2_ai/prepare_input.py --split validation --output /tmp/b2-input.json
```

## Полный запуск будущего агента

```bash
python benchmarks/b2_ai/run_benchmark.py \
  --split validation \
  --output-dir runs/b2-validation \
  -- your-agent --input {input} --output {output}
```

Вместо placeholders агент может читать `B2_INPUT` и `B2_OUTPUT`.

## Граница доказательства

Автоматически считаются классификация, критичное в низком, дословность evidence, группировка событий и связи/стадии НПА. Полнота смысла, отсутствие перефразированной галлюцинации и сохранность разных позиций уходят в `judge_packet.json`; они намеренно не подменены keyword-эвристикой. RAT остаётся заблокирован до получения полных оригиналов и человеческих замеров.
