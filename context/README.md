# Исходный контекст backend-команды

Эти файлы использовались при создании `sources.json` и первого processing-контура. Они сохранены как происхождение технических решений, а не как отдельная продуктовая истина.

- `task.md` — исходная постановка кейса;
- `company_info.md` — исходный профиль компании;
- `sources_for_company.md` — исследование источников для сборщика;
- `tables_pr_gr_heads.md` — рабочая разбивка источников по ролям.

Актуальная продуктовая постановка, проблемы, гипотезы и план находятся в [`project/README.md`](../project/README.md).
