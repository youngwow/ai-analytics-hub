# GS Labs Context Truth Pack v1

Замороженная доказательная реконструкция контекста для B2/B4. Это не скрытая внутренняя рубрика GS Labs и не пользовательский пилот.

## Приоритет источников

1. письменный кейс;
2. ответы кейсодателя в чате и на Q&A;
3. предоставленный Excel как пример текущей работы, но не идеальный эталон;
4. проверенный внешний ресёрч — только для публичного профиля и карты источников;
5. выводы команды, всегда помеченные `inference` или `assumption`.

## Файлы

- `context.json` — контекст, который может видеть продукт;
- `claims.jsonl` — реестр оснований с типом, уверенностью и точным местом;
- `checksums.sha256` — заморозка до B2-разметки.

## Правило использования

Gold не может ссылаться на знание, которого нет в `claims.jsonl` или оригинальном материале сценария. Неизвестное остаётся неизвестным. Изменение pack создаёт новую версию и требует нового holdout.
