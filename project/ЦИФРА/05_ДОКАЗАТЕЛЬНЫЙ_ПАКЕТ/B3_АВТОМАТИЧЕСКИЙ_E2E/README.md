# B3 — автоматический E2E

> **Вердикт:** выбранный автоматический контур жизнеспособен как review-first агент. B3 проверил совместную работу компонентов до `DraftDigest`, поиск, доресерч, НПА и рост банка до 10 000 объектов.

## Один вопрос

Работают ли выбранные в B1/B2 компоненты совместно на реалистичном потоке во времени, включая сложные события и НПА, и выдерживают ли архитектурные решения масштаб?

## Почему B2 недостаточно

B2 оценивает отдельный ответ модели. B3 даёт агенту состояние мира, поток материалов и время, затем проверяет полный путь: сохранение → анализ → связи → НПА → review-policy → итоговые объекты → черновик доставки.

## Что находится внутри

```text
initial state + timed source streams + Context Truth
                         │
                         ▼
replay boundary → ProductAgentRuntime → isolated SQLite
                         │
                         ▼
item decisions + events + NPA history + review set + DraftDigest + delivery plan
                         │
                         ▼
deterministic scorer + отдельные H1 / A2 / A3 experiments
```

### Вход

- два обычных окна A/B и четыре диагностических сценария D1–D4;
- 58 материалов после replay-границы B1;
- разные источники, времена, дубли, разные позиции, критичный кейс;
- новый НПА, обновление уже известного НПА и отдельный терминальный EXP принятия/даты действия/архива;
- начальный банк событий/НПА и отдельные банки 100 / 1 000 / 10 000 для scale;
- Context Truth и gold, невидимые агенту.

### Работа

1. Запускает настоящий `ProductAgentRuntime` в изолированной БД.
2. Сравнивает `fixed / search / hybrid` на одинаковых окнах.
3. Сравнивает сигнал без доресерча и с targeted Tavily research.
4. Проверяет full scan против embeddings top-20 на растущем банке.
5. Проверяет events, NPA lifecycle, review-policy и lossless release.
6. Отдельно проверяет, что принятый НПА нельзя архивировать до даты действия и можно безопасно архивировать после неё.
7. После найденного критичного ролевого дефекта повторяет D1 на свежем run.

### Выход

- decisions по 58 материалам;
- 18 итоговых объектов для B4;
- события с источниками и история НПА;
- DraftDigest и delivery plan;
- latency/tokens/errors и выбранные ветки архитектуры.

## Главные результаты

| Граница | Получено | Решение |
|---|---:|---|
| Full E2E | 0 ошибок контракта; все evidence quotes дословны | Контур работает как review-first |
| Relevance / importance / roles до policy fix | 55/58 · 43/58 · 42/58 | Автономное скрытие по ролям запрещено |
| Event grouping | 34/34 размеченных связей без false merge/split | Событийная модель сохранена |
| H1, окно A | fixed 6/7 · search 3/7 · hybrid 7/7; шум 7/1/8 | Search-only убит; always-on hybrid не принят |
| H1, окно B | fixed 6/6 · search 2/6 · hybrid 6/6; шум 7/1/8 | Постоянные источники — база, поиск целевой |
| A2 research | принято 5/7 news и 11/13 NPA фактов; 76,3 и 201,4 с | Только асинхронно и с review |
| A3 scale | top-20 нашёл 4/4 event и 3/3 NPA связей; full scan превысил контекст | Embeddings top-20 приняты с первого дня |
| NPA terminal lifecycle | 9/9 инвариантов: дата действия, явный архив, idempotency, история и изоляция | Терминальный контур принят |
| Critical core | свежий D1: роли 3/3, critical виден PR/GR/HEAD | Критичное стало общим ядром |

## Какие гипотезы закрыл B3

- `H1` — исходная always-on hybrid-гипотеза убита; принят постоянный сбор + целевой поиск;
- `H3` — техническая часть событийной группировки подтверждена;
- `A2` — исходное обещание research без неприемлемых издержек убито; принят ограниченный асинхронный режим;
- `A3` — embeddings candidate retrieval подтверждён на масштабе;
- обязательные сценарии нового, обновлённого и терминального НПА прошли;
- H2/H4/H5 получили сравнимые выходы для содержательной оценки B4.

## Сдвиг после B3

Архитектура перестала быть «одна LLM делает всё». Появились доказанные границы: постоянный ingestion, быстрый one-pass, явные unknowns, точечный research, embeddings top-20 с первого дня, отдельные event/NPA lifecycle и review-first release.

## Чего B3 не утверждает

- естественную частоту всех ошибок в промышленном потоке;
- человеческое время и удобство;
- абсолютную полноту интернета;
- безопасность автопубликации.

## Готовый тезис для слайда

> B3 запустил выбранный AI-контур в реалистичном потоке, а не на отдельных строках. Контур собрал события и НПА, сохранил evidence и прошёл без контрактных ошибок. Эксперименты убили search-only, постоянный hybrid и обязательный research; масштабный тест доказал необходимость embeddings top-20, а критичный повтор закрепил общее ядро PR/GR/HEAD.
