# B4 — контекстная продуктовая оценка

> **Вердикт:** результат агента сохраняет обязательное содержание, позволяет сократить обязательную проверку и поддерживает событийную модель. Жёсткое автоматическое разделение PR/GR не прошло и заменено общей очередью с фильтрами.

## Один вопрос

Даёт ли автоматический контур результат, который соответствует известным интересам GS Labs, сохраняет критичные факты и неопределённости и безопасен как рабочий черновик для PR/GR?

## Зачем нужен B4

B1 проверяет получение данных, B2 — отдельные AI-механизмы, B3 — их совместную работу. B4 проверяет уже **содержательный результат**: не потерялось ли важное между исходным материалом и короткой повесткой.

Это не опрос заказчика. Истина собрана командой из кейса, чата, расшифровки встречи и Excel. Поэтому B4 закрывает внутреннюю содержательную проверку, но не подменяет пилот с живыми PR/GR.

## Что находится внутри

```text
кейс + чат + созвон + Excel
            │
            ▼
      Context Truth
важно · неважно · роли · риски · ограничения
            │
            ├──────────────┐
            ▼              ▼
 frozen B3 originals   scenario gold
            └──────┬───────┘
                   ▼
         frozen B3 output (18 объектов)
                   ▼
 deterministic counts + ручной source-to-result audit
                   ▼
       решение по H1–H5 и границы вывода
```

### Вход

- замороженный Context Truth GS Labs;
- исходные материалы и object truth из B3;
- шесть выбранных прогонов B3: A, B, D1–D4;
- 18 ожидаемых объектов с обязательными сведениями, ролями и рисками;
- итоговые карточки, события и НПА агента.

### Работа

1. `build_packet.py` собирает только заранее выбранные прогоны.
2. `manifest.json` фиксирует хэши всех входов и результата.
3. Детерминированный scorer считает достижимость, очередь review, состав событий, роли и top layer.
4. Каждый из 18 объектов вручную проверяется по цепочке `исходник → gold → результат → роли`.
5. Критичный промах, ложный статус НПА, потеря факта или неподтверждённое утверждение нельзя скрыть средним баллом.

### Выход

- воспроизводимый judge packet и manifest;
- детерминированный scorecard без искусственного общего процента;
- ручной аудит 18 объектов;
- бинарное решение по каждой продуктовой гипотезе на заявленной границе;
- изменения продуктовой политики и архитектуры.

## Главные результаты

| Проверка | Результат | Решение |
|---|---:|---|
| Сохранность содержания | 18/18 ожидаемых объектов сохранили обязательные сведения и неизвестные | `H5` подтверждена по содержанию |
| Выборочная проверка | 28/28 размеченных рисков попали в review; очередь 39 вместо 58 материалов | `H2` подтверждена на Context Truth |
| Событийная сборка | 18/18 объектов имеют точный ожидаемый состав; B3 дал 34/34 связей | `H3` подтверждена |
| Строгая адресация | PR/GR получили пропуски и лишние элементы в A/B | исходная `H4` убита |
| Критичное общее ядро | свежий D1: роли 3/3, critical виден PR/GR/HEAD | системное правило принято |
| LLM-судья | протокол пропустил реальную потерю и создал ложные отклонения | не используется как источник истины |

## Какие гипотезы закрыл B4

- `H2` — **подтверждена на внутреннем gold:** risk-only сохранил 28/28 известных рисков и уменьшил очередь на 19 материалов;
- `H3` — **подтверждена:** события сократили число объектов без потери обязательных фактов и разных позиций;
- `H4` — **убита в строгой форме:** ролевые метки недостаточно надёжны для скрытия; выбрана одна очередь с неразрушающими фильтрами;
- `H5` — **подтверждена по содержанию:** короткий слой сохранил 18/18 ожидаемых объектов; удобство живого пользователя остаётся внешней проверкой;
- `H1` — B4 закрепил смысл решения B3: постоянные источники дают основу, а поиск используется только для конкретного пробела.

## Сдвиг после B4

До B4 роли могли скрыть сигнал, а часть неопределённостей терялась при короткой проекции. После проверки:

- роли стали фильтрами общей очереди, а не правами на сокрытие;
- `critical/urgent` всегда входит в общее ядро PR/GR/HEAD;
- `unknowns` явно проходят в короткий результат;
- выпуск закреплён как review-first, а не автономная публикация.

## Чего B4 не утверждает

- что PR/GR действительно сократят работу с 3–4 часов до конкретного числа минут;
- что пользователи доверяют карточкам и интерфейсу;
- что Context Truth равен внутренней разметке заказчика;
- что синтетическая частота событий совпадает с продом;
- что агент может безопасно публиковать результат без человека.

## Готовый тезис для слайда

> B4 проверил не красоту ответа, а сохранность смысла: все 18 ожидаемых объектов сохранили обязательные сведения, а выборочная проверка поймала 28 из 28 известных рисков при очереди 39 вместо 58 материалов. Одновременно эксперимент убил жёсткую адресацию PR/GR: роли оставлены фильтрами общей очереди, критичное стало общим ядром, а неизвестные — обязательной частью короткого результата.
