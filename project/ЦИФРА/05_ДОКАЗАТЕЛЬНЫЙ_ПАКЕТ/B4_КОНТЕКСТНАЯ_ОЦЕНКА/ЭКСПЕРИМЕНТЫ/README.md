## EXP-B4-03 — H3: публикации / события

Сравнивается плоский поток материалов с ожидаемыми предметными объектами. Состав объекта считается правильным только при точном совпадении материалов; ложная склейка и пропуск не компенсируют друг друга.

| Проверка | Результат |
|---|---:|
| Ожидаемые итоговые объекты | 18 |
| Объекты с точным составом | 18/18 |
| Размеченные связи B3 | 34/34 |
| Объекты, прошедшие ручную проверку содержания | 18/18 |

**Решение:** `H3` подтверждена. Событийная модель сокращает дублирующие публикации и сохраняет обязательные факты, источники и независимые позиции.

Доказательства: [B4 scorecard](../../../../../artifacts/b4/deterministic_scorecard.json), [B4 audit](../../../../../artifacts/b4/B4_MANUAL_AUDIT.md), [B3 scorecard](../../../../../artifacts/b3/B3_SCORECARD_V3.json).

## EXP-B4-04 — H4: строгая адресация / общая очередь

В A/B проверено, можно ли автоматически скрывать элементы одной роли от другой.

| Поток | Наблюдение |
|---|---|
| A | PR: 2 пропуска и 1 лишний объект; GR: без ошибок |
| B | PR: 3 лишних объекта; GR: 2 пропуска |
| Ручной аудит | J04/J11 пропустили HEAD; J09 получил неверную роль |

**Решение:** строгая версия `H4` убита. Автоматическая роль используется как фильтр и подсказка общей очереди, но не скрывает материал. Для `critical/urgent` введено общее ядро; свежий D1 после исправления прошёл роли 3/3.

Доказательства: [scorecard](../../../../../artifacts/b4/deterministic_scorecard.json), [аудит](../../../../../artifacts/b4/B4_MANUAL_AUDIT.md), [D1 prediction после fix](../../../../../artifacts/b3/runs/v4_policy_D1_critical_hybrid/prediction.json), [правило](../../../../../src/product/contracts.py).

## EXP-B4-05 — H5: полный поток / короткий верхний слой

Для каждого объекта проверялись обязательные факты, даты, стадии, позиции источников, оговорки и `unknowns`. Проверка проводилась по исходнику, а не по впечатлению от summary.

| Проверка | Результат |
|---|---:|
| Материалы рабочего потока | 58 |
| Ожидаемые объекты верхнего слоя | 18 |
| Точно присутствующие объекты | 18/18 |
| Критичные объекты, потерянные сверху | 0/1 |
| Объекты с сохранённым обязательным содержанием | 18/18 |

**Решение:** `H5` подтверждена по содержательной достаточности. Поведенческая достаточность — сможет ли человек не открывать всю ленту — остаётся задачей реального пилота.

Доказательства: [ручной аудит](../../../../../artifacts/b4/B4_MANUAL_AUDIT.md), [scorecard](../../../../../artifacts/b4/deterministic_scorecard.json), [release projection](../../../../../src/product/release.py).

## EXP-B4-06 — проверка самого LLM-судьи

Исторический GPT-OSS judge пропустил реальную потерю в J07 и дал ложные отклонения в четырёх других случаях: протокол разрешал подтвердить критерий исходной цитатой, не доказав наличие критерия в ответе агента.

**Решение:** LLM-судья отклонён как acceptance gate. Для 18 объектов источником решения является ручной source-to-result аудит, а старые judge-файлы сохранены только как отрицательное доказательство качества метода оценки.

Доказательства: [объяснение дефекта](../../../../../artifacts/b4/B4_MANUAL_AUDIT.md), [debug artifacts](../../../../../artifacts/b4/judges/debug/).

## Итог B4

`Context Truth → frozen outputs → deterministic counts → manual semantic gate → product policy`.

Подтверждены `H2`, `H3`, `H5` на внутренней содержательной границе. Строгая `H4` убита. Главная ценностная гипотеза поддержана структурно, но фактическая экономия времени, доверие и удобство не объявляются измеренными без пилота.
